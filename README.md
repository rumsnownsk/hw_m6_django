Учебный проект на Django (модуль 6, курс Sky.Pro): каталог и страница контактов, работа с формами. Проект входит в курсовую работу по анализу вакансий и базе данных.

## Стек технологий

- Python 3.12
- Django 6.1.1
- Poetry (управление зависимостями и виртуальным окружением)
- PostgreSQL (планируется для курсовой)
- HTML + Bootstrap 5 (шаблоны)

## Что уже реализовано

- Страница `/` — главная (заглушка).
- Страница `/contacts/` — форма обратной связи (GET/POST в одном view).
- Приложение `catalog` — базовая структура для каталога товаров.
- Настройка Poetry-окружения, корректные пути активации.

## Как запустить

### 1. Установи зависимости через Poetry
```bash
poetry install
```

### 2. Запустить сервер
```bash
poetry run python manage.py runserver
```

### 3. Проект будет доступен по адресу:

http://127.0.0.1:8000/
